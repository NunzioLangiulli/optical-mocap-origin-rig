# Sources and attribution

The CAD was developed for this project. References below support software workflow, printer envelope or general material handling; they do not validate the rig's printability or performance.

1. **Vicon — Set the volume origin, Nexus 2.15 documentation.** Supports the origin → primary X → secondary Z selection order for the manual Three Markers option. Follow the installed-version prompts. [Official help](https://vicon-help.atlassian.net/wiki/spaces/Nexus215/pages/11374576/Set%2Bthe%2Bvolume%2Borigin).
2. **Vicon — Nexus 2.18 User Guide, “Calibrate a Vicon system.”** Also describes the Three Markers order. [Official PDF](https://help.vicon.com/download/attachments/406490967/Vicon%20Nexus%20User%20Guide.pdf).
3. **Bambu Lab — X1E technical specification.** Reference for the nominal 256 × 256 × 256 mm build volume. [Official specification](https://cdn1.bambulab.com/x1e/spec/X1E%20Spec%28EN%29.pdf).
4. **Bambu Lab — ABS material information.** General enclosure, brim and drying guidance. [Material page](https://bambulab.com/filament/abs). Availability and product profiles can change; use the current profile for your spool and printer.
5. **Nikon — Using a tripod with a Nikon camera.** Explains the 1/4-20 UNC tripod connection and the need to consider screw projection. This does not certify the printed socket. [Manufacturer guidance](https://www.nikonimgsupport.com/eu/BV_article?articleNo=000044686&configured=1&lang=en_GB).
6. **Creative Commons — Attribution 4.0 International.** [License deed](https://creativecommons.org/licenses/by/4.0/) and [legal code](https://creativecommons.org/licenses/by/4.0/legalcode.txt).

Third-party manuals, logos and product photographs are not included in the repository. Generated views depict this project's mesh and synthetic marker spheres only. The 60° roof/bracket inclination is a project design choice, not a manufacturer-certified ABS adhesion limit.

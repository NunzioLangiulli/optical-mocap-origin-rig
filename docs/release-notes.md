# v0.2.0 — Origin rig design v7 (digital prototype)

One full-rig STL provides five mounting positions. M100 is a new cylindrical 18 mm diameter pedestal on the X arm, 100 mm from O, at the same face height. Original O/X150/Y150/Z150, socket, downward channels and rear-open tower remain.

Vicon: use O/X150/Z150, with Y150 as optional check. Motive Custom Calibration Square: use O/M100/Y150 only. This satisfies the documented unequal-arm right-angle geometry; physical use is untested. No camera-calibration wand is replaced.

Includes STL, unchanged coupons, CAD source, geometry tests, English instructions and previews. Target: Bambu X1E, black ABS and nominal 12 mm adhesive markers. Envelope 191 x 174 x 174 mm; mesh volume approximately 101.35 cm3. Slicing, physical print and acquisition-system validation remain pending.
